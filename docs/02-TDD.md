# Все овечки должны быть пострижены — техническое ТЗ

Устроено так же, как Cubocalypse («3d survival»): pnpm-воркспейс, React Three Fiber, koota, zustand, Vite, TypeScript strict, Vitest.

## 1. Стек

| Что | Чем |
|---|---|
| Сборка | Vite 8, `base: './'` в сборке, поэтому папку `dist` можно выложить куда угодно |
| 3D | three 0.185, @react-three/fiber 9, @react-three/drei 10 (`Html` для подписей на поле) |
| Состояние мира | koota 0.6: ресурсы мира (`res(world, X)`) |
| Состояние интерфейса | zustand 5 (`app/store.ts`, `ui/hudStore.ts`, язык) |
| Тесты | Vitest 5 в Node, без отрисовки |
| Стиль | ESLint 9 + typescript-eslint, Prettier: `semi: false`, `singleQuote`, `printWidth: 200` |

Физики нет: игра на сетке, Rapier не нужен.

## 2. Пакеты

| Пакет | Что это |
|---|---|
| `packages/game` (`@ws/game`) | Игра. `pnpm dev` |
| `packages/input` (`@kit/input`) | Действия клавиатуры по `KeyboardEvent.code`: `held()` и `on()` |

Правило как в Cubocalypse: `@kit/*` — переиспользуемые библиотеки. Они не импортируют `@/`, у каждой один вход `src/index.ts`.

## 3. Симуляция (`packages/game/src/game`)

Это чистый TypeScript без React и three. Его гоняют тесты и бот в Node.

| Файл | Что в нём |
|---|---|
| `balance.ts` | все числа: карта (`GRID`, `MAP`), портал (`PORTAL`), виды овец (`KINDS`, `KIND_ORDER`), прилёт (`ARRIVE`), цель (`GOAL`), постройки с ценой рецепта и штуки (`BUILDINGS`), морковка (`CARROT`), пугало (`SCARE`), вода для Мойки (`WATER_REACH`), правила делителя (`SPLIT_RULES`), цвета (`LOOK`) |
| `land.ts` | `makeMap(seed)`: холмы, пруды, пятна луга, кустов, ёлок, камней на всей карте, одинаково для одного зерна; клетки вокруг портала голые |
| `world.ts` | типы данных, ресурсы koota, `createGameWorld` (карта, портал, стадо с начала), `makeSheep`, `ready` |
| `start.ts` | `startWorld` = мир и первая карточка «Стрижка» |
| `grid.ts` | чистые вопросы о сетке: что стоит, входы и выходы, `whyNot` (холм, вода, занято, `needWater` у Мойки, `sheepHere` — где стоит овца), `circle`, `waterNear`, `sheepOn` |
| `systems/` | системы шага (`index.ts` — порядок): `arrive`, `sheep`, `belts`, `machines`, `portal` (приём, монеты, цель), `unlocks` (карточки, рецепты) |
| `actions/` | команды игрока: `build` (рецепт, стройка, снос, перенос, поворот, правила делителя), `path` (ленты по двум кликам), `hand` (стрижка, перенос овцы) |
| `lines.ts` | линия «морковка → лента → Стрижка → вход портала» по клеткам: её строят бот, ферма за меню и тесты |
| `bot.ts` | бот баланса |
| `showcase.ts`, `stress.ts` | фабрика за меню и огромная фабрика для замеров |

### 3.1 Ресурсы мира
`Time`, `GameState` (зерно карты `seed`, часы, монеты, скорость, `shorn` — сколько ушло в портал, `won` и `wonAt`, время до прилёта `arriveT`, `fieldVersion` и `plantVersion`), `Field` (рельеф `terrain`, холмы `hills` и их ступени `hillRects`, края карты), `Plant` (постройки по клеткам), `Flock` (овцы), `Unlocks` (купленные рецепты `unlocked`, новые на панели `fresh`, очередь карточек), `Ui` (инструмент, поворот, выбор, наведение, овца в руке `drag`, постройка в переносе `moving`), `Fx` (очередь эффектов), `Stats`, `Rng` (детерминированный, `rng.ts`), `Systems` (какие системы включены, 3.4).

Постройки и овцы — обычные объекты внутри ресурсов. Постройка лежит в `Plant.b` под своей верхней левой клеткой, остальные клетки 2×2 ведут к ней через `Plant.occ`; `get(x, y)` находит постройку по любой её клетке. `outCells(b)` — клетки выходов (у станции и морковки один, у делителя три, у пугала и портала нет), `inCell(b)` — единственный вход станции (задняя клетка на линии выхода), `machineIns`, `dockIns`, `inCells` — входы с тем, что каждый берёт (`takes`: работа станции или `portal`), `entersAt` решает, через какой вход пришла овца. Ключ — клетка `"x,y"`.

Овца (`SheepT`): вид `kind`, что ей ещё нужно `needs` (из `KINDS[kind].needs`), шерсть `wool` (1 пушистая, 0 стриженая), состояние `roam` / `belt` / `machine` / `held`, место в клетках, `drop` — сколько ей ещё лететь на парашюте. `ready(s)` — пушистая и ничего не нужно. `nextFor(s)` (`systems/machines.ts`) — что ей нужно первым: станция, стрижка или портал.

### 3.2 Шаг
`stepSimulation(world, FIXED_DT)`, шаг 1/60 с, идёт по таблице `STEPS` (`systems/index.ts`); каждый шаг делается, только если его система включена:
1. `arrive` — прилёт: держит стадо у планки `flockBar` (`ARRIVE.bar` + `ARRIVE.perShorn` за каждую стриженую, не больше `ARRIVE.most` и `SHEEP.most`), новые виды открываются по счёту (`KINDS[k].at`, карточка), на полной карте прилёт ждёт;
2. `sheep` — овцы бродят по свободной земле; пушистые в круге морковки идут к ней и толпятся (`CARROT`); из круга пугала уходят и не заходят (`SCARE`); круги кэшируются по `plantVersion`;
3. `belts` — овцы на лентах; делитель шлёт овцу на сторону, чьё правило ей подходит (`ruleFits`), по кругу между подходящими; портал принимает только стриженую (`dockAccept`);
4. `machines` — станция берёт только овцу своей работы (`takesSheep`), иначе овца стоит у входа (`wrong`) и линия за ней стоит; через `time` секунд снимает с овцы нужду или стрижёт и выпускает её на выход; морковка каждые `time` секунд ставит ближнюю пушистую из круга на свой выход;
5. `goal` — цель достигнута: `won`, карточка победы, игра идёт дальше.

Пока поднята карточка «Новое» или стоит пауза, мир не идёт (`isFrozen`).

### 3.3 Эффекты
Симуляция ничего не рисует и не играет. Она кладёт в `Fx` события «число всплыло», «облачко», «звук» и «портал» (стриженая овца ушла во вход: клетка и монеты). Вид разбирает очередь каждый кадр. Без отрисовки очередь ограничена 400 событиями.

**Звуки** (`src/audio/index.ts`) — записи автора из `public/sfx`: `place` (постройка поставлена), `remove` (снесена) — события симуляции; `click` — любая кнопка интерфейса. Тот же звук не чаще раза в 70 мс.

### 3.4 Системы и выключатели
Игра разбита на системы с именами (автор, 17.10.2026). Список — `SYSTEMS` в `world.ts`, мир держит включённые в `Systems.on`, проверка — `isOn(world, id)`.

| Система | Что делает | Где проверяется |
|---|---|---|
| `arrive`, `sheep`, `belts`, `machines`, `goal` | шаги симуляции | `stepSimulation` |
| `floats`, `sound` | всплывающие числа и звуки | `emit` |
| `keys` | клавиши на поле (Esc и Enter для карточки, справочника и меню работают всегда) | `GameLoop` |
| `pointer` | мышь и тачпад на поле: рука, стройка, камера | `Scene` |
| `ghost` | что в руке: предпросмотр, сетка клеток, круги | `Scene`, `Ground` |
| `hover` | обводка под курсором | `Scene` |
| `tags` | знаки на поле: над овцой, остановившей станцию, и над морковкой без овец | `Machines`, `SheepView` |
| `portIcons` | значок у каждой стрелки входа и выхода | `Ghost` |
| `hud`, `fps` | панели экрана, счётчик кадров | `GameLoop`, `Scene` |
| `orbit` | камера сама медленно облетает фабрику | `Scene` |

`PLAY` — игра: всё, кроме `orbit`. `DEMO` — фабрика за главным меню, только посмотреть: прилёт, овцы, ленты, станции и облёт камеры. Без `goal` счёт не растёт, новые виды не прилетают, поэтому её линии не встают.

### 3.4.1 Портал
Портал — одна постройка `dock` `PORTAL.size`×`PORTAL.size` в середине карты (`addPortal` в `world.ts`). Её нельзя снести и поднять. Восемь входов — по два на сторону (`PORTAL.ports`, `dockIns`). Стриженая овца входит (`intoPortal`): уходит с карты, `shorn` растёт, монет `SHEEP.coins`, событие `portal`. Пушистая стоит у входа со знаком, как у станции. Рука сдаёт стриженую в любую клетку портала.

### 3.5 Сохранение
`game/save.ts` — чистый: `saveGame(world)` отдаёт всю игру как JSON, `loadGame(data, opts)` строит из неё мир, который идёт дальше точно так же (в сохранении и состояние генератора). Ресурсы мира — массивы вместо `Map` и `Set`; овца на ленте и в станции хранится номером; `Plant.occ` строится заново; карта (холмы) берётся из зерна. Не сохраняются очередь эффектов, включённые системы и знак «не та овца». Постройка в переносе сохраняется на старом месте; овца в руке опускается и бродит.

`SAVE_VERSION` = 9; сохранения старой игры (товары, загоны) не загружаются. `app/saves.ts`: одно сохранение `ovf.game` в `localStorage`, всё в try/catch. `RunScreen` пишет его сразу, каждые `SAVE.everySec` секунд, когда страница прячется и при уходе с экрана. Главное меню читает `savedInfo()` — сколько пострижено и время — и показывает «Продолжить». Тесты — `save.test.ts`.

## 4. Отрисовка (`packages/game/src/render`)

### 4.1 Цикл кадра
`GameLoop` — единственный `useFrame(..., -100)`. Он делает пять вещей:
- накапливает время × скорость и делает фиксированные шаги (до 8 за кадр);
- собирает `frame` — где сейчас каждая овца и каждая лента (`frame.ts`);
- раз в 6 кадров обновляет HUD (`pushHud`, подсказка сверху — `hintOf`);
- обрабатывает клавиатуру;
- держит консоль `__game`.

### 4.2 Виды
- **Земля.** `Ground` — остров-диорама: травяной верх с бортиком над земляными боками, висит на голубом фоне. Верх — один плоский скруглённый прямоугольник с нарисованной текстурой (32 пикселя на клетку). Зелень с пятнами рисуется один раз (`paintBase`); поверх её копии — вытоптанная земля и контактные тени у построек и пашня под лугом, заново только при `plantVersion` или `fieldVersion` и не чаще раза в 0,3 с (`REPAINT`: протяжка ленты меняет постройки каждые несколько кадров). Сетка клеток — второй прозрачный слой: плитка одной клетки, повторённая по всему верху (`gridTile`), видна только при стройке.
- **Мелкие объекты.** Всё, чего много, рисуют instanced-сетки (`instancing.ts`, `Batch`): `Terrain` (луг и кусты с ягодами — только декор, перестраиваются по `fieldVersion`), `Belts`, облачка.
- **Ленты.** Деревянные, как в Tower Factory: тёмное ложе, светлые планки бегут вместе с овцами, бортик на каждой стороне, через которую лента не проходит.
- **Подписи на поле.** drei `Html`, `pointer-events: none`.
- **Предпросмотр** (`Ghost.tsx`). Здание и лента в руке выглядят одинаково.
  - Модель в своих цветах, поднята на 0,24 клетки, под ней полупрозрачный голубой блок до земли размером с основание (`blockOf`).
  - Кремовая обводка `@kit/outline` (оттенок `place`) только вокруг модели.
  - Вход — розовая стрелка, выход — голубая, рядом значок того, что идёт (`inGood`, `outGood`). У соседних построек — их входы и выходы, которые касаются места.
  - Если поставить нельзя: красный блок, красная обводка, модель чуть краснее, причина над ней (`WHY_TEXT`, в том числе «тут овцы»).
  - Круг (`circleOf`): у морковки — `CARROT.radius`, у пугала — `SCARE.radius`, у Мойки — `WATER_REACH`. Всё внутри окрашено холодным голубым (`reach.ts`, радиус — `uReachR`), по краю лимонное кольцо. От каждой пушистой овцы, которую позовёт морковка, и от каждой клетки воды для Мойки — лимонный пунктир; у морковки и пугала — число овец в круге. Круг виден и там, где поставить нельзя: место выбирают по нему.
  - Лента в руке: настоящие куски на одном блоке, цена у курсора.
  - Поставленная машина опускается с высоты 0,24 и приседает (`DROP` в `Machines.tsx`).
- **Что под курсором** (`pickAt` в `pick.ts`). Ближайшая модель, в которую упирается луч: овца (по модели в позе; кроме летящей на парашюте), машина, портал. `Hover` ищет это каждый кадр и обводит.
- **Мышь** (`Pointer.tsx`). Клик рукой по пушистой овце — щелчок ножниц (у неготовой ничего), по модели машины — её окно. Протяжка рукой по овце несёт её (`pickSheep`), отпустить — `dropSheep`: на ленту, в станцию, которая её берёт, стриженую в портал, иначе бродит. Протяжка по пустой земле двигает камеру. Ленты — двумя кликами или протяжкой, снос — протяжкой. Правая кнопка по постройке поднимает её для переноса.
- **Экраны** (`app/App.tsx`). `title` — главное меню (`TitleScreen`: мир с системами `DEMO` и фабрикой `buildShowcase`; `ui/Title.tsx`), `run` — игра. `?play` в дев-сборке сразу запускает игру.
- **Пауза.** Одна — `GameState.speed` = 0. На паузе рука не стрижёт и не берёт овец; попытка увеличивает `pauseNudge`, и строка паузы вздрагивает.
- **Окно постройки** (`Popup` в `Hud.tsx`): что она делает с овцой (`recipeOf`: вид → готовая, готовая → стриженая), состояние (`machineState`: «не та овца» и что ей нужно, «выход занят», «ждёт овцу», «овец рядом»), полоска работы (`JobBar`: `jobProgress`, `cycleTime`), правила делителя (`cycleRule` по `SPLIT_RULES`, значок — вид овцы), перенос и снос. Окно портала — счёт и монеты за овцу.
- **Знак** (`MachineView` в `Machines.tsx`). Над овцой, которая стоит у входа станции или портала и остановила линию, — красный пульсирующий знак «!» и значок того, что ей нужно первым. Над станцией с занятым выходом — «!». Над морковкой без пушистых овец в круге — значок овцы.
- **Панель и справочник.** Ячейки панели — `bar` в `app/store.ts` (`ovf.bar`), показ — `barOf`: купленный рецепт без места занимает первую пустую ячейку. Клавиши 1–0, X — снос, B — справочник (`ui/Book.tsx`): постройки с ценой рецепта на плитке и кнопкой «Купить рецепт» (`buyRecipe`), вкладка видов овец — что каждому нужно и после скольких стриженых он прилетает. Пока справочник открыт, мир стоит.
- **Один принцип для всех построек** (автор). Входы — `inCells`, выходы — `outCells`, из них же стрелки при постановке и наведении (`showFlow`).
- **Перенос** (`liftUp` / `putDown` / `putBack` в `build.ts`). Правая кнопка или кнопка окна поднимает постройку со всем, что в ней; встаёт по клику бесплатно; Esc возвращает её на место. Портал не переносится.
- **Бродячие овцы** (`systems/sheep.ts`, числа — `ROAM`). Ходят по земле без построек, холмов и `ROAM.blocking`; лента проходима, но цели на ней не бывает. Если под овцой выросла постройка, она уходит на ближайшую свободную клетку (`shooRoamers`). Над лентой овцу поднимает `frame.ts` (`lift`). Прилетевшая спускается на парашюте (`dropPose` в `sheepLook.ts`); пока `drop` есть, её не трогают ни система, ни рука.
- **Часы анимаций** (`frame.t`). Всё, что движется на поле, идёт по часам игры: со скоростью игры, стоит на паузе и под карточкой.
- **Модели.** Файлов моделей нет: всё собрано в коде из мягких примитивов и склеено в одну геометрию с цветами вершин. `models.ts`: природа, овцы, портал, мелочи. `machineModels.ts`: постройки. `kit.ts`: общие материалы и геометрии.
- **Постройки** (`machineModels.ts`). Механизмы, как в Tower Factory, у каждой одна большая рабочая деталь: Стрижка — шатёр с ножницами, Мойка — банька с паром и кадкой воды, Расчёска — арка со щёткой и огромный гребень, Щипалка — арка с огромным пинцетом и корзина репьёв, морковка — морковь-статуя на постаменте (качается, пока ставит овцу), пугало — на земляном холмике, с вороной на руке. Станции — арки, овцы входят сзади и выходят спереди через калитки по левой половине (`gates`). Модель строится лицом на юг и поворачивается целиком (`machineYaw`).
- **Овцы** (`sheepLook.ts`). По шерсти видно, что овце ещё нужно: грязная бурая (`LOOK.dirtFleece`), нечёсаная свалявшаяся (`fleeceFelt`), с репьями — в коричневых колючках (`fleeceBurrs`); смешанные — всё вместе. Станция снимает свою метку. Пузырей над стадом нет: что нужно овце, говорит курсор.
- **Портал** (`Portal.tsx`, `portalModel` в `models.ts`): каменная площадка 8×8 с плиткой, круглый помост, стоячее каменное кольцо с рунами и вихрь внутри (крутится всё время), у каждого входа деревянный жёлоб с шевронами. Событие `portal` (`startPortal`): стриженая овца скользит по жёлобу к кольцу и уменьшается в нём, с кольца взлетает монета.
- **Трава** (`Grass.tsx`). Густой низкий газон из широких листьев покрывает всю свободную землю: пучки сеткой 6×6 на клетку со сдвигом, растут и вокруг деревьев, камней и кустов, у постройки или ленты короче и темнее; нет на постройках, лентах, воде и лугу; повёрнуты к камере, качаются на ветру, нормали вверх, глубину не пишут. На всей карте около 450 тыс. пучков, поэтому газон разбит на куски `GRASS.chunk` = 16 клеток: кусок вне кадра не рисуется (своя сфера отсечения), куски идут от дальних к ближним (`renderOrder` по взгляду камеры), перекладывается только кусок, где поменялись постройки рядом или вода и луг (`signatures`), и не чаще раза в 0,3 с (`RELAY`). Дальше `GRASS.far` клеток пучок — пиксель, газон не рисуется. По умолчанию выключен, кнопка внизу справа (`ovf.grass`).
- **Карта** (`island.ts`). Поле 112×112 клеток, вся земля своя. Остров — поле и `ISLAND.margin` = 1 клетка травы вокруг; забор края по краю поля, ёлки на кромке (`rimTree`). `Scene` кладёт в `island` края и холмы мира до того, как части острова строятся.
- **Холмы** (`Hills.tsx`, `hillShape.ts`). Карта холмов — из `makeMap`: прямоугольники второго и третьего уровня (`Field.hillRects`), по клеткам — `Field.hills`, спрашивают через `levelAt`. На холме ничего не строится (`whyNot` → `hill`), овцы на него не ступают. Вид — ступень земли со скруглёнными углами и травяной шапкой; шапка третьего уровня светлее.
- **Вода** (`Water.tsx`). Поле по 8 точек на клетку, размыто, изолиния — берег; гладь, бортик, кувшинки и блики. Моря нет.
- **Мелочи.** `Decor`: цветы и грибы кучками, у воды, холмов, построек и края; под постройкой исчезают. `Props`: забор по краю, деревья по дальнему краю.

### 4.2.1 Свет и подсветка
- **Мультяшный свет.** Материалы `MeshToonMaterial` с тремя полосами света, тёплое солнце, небесная подсветка, мягкие тени.
- **Без пост-обработки.** Холст рисует прямо на экран, сглаживание — встроенное MSAA браузера, тональной коррекции нет (`flat`): цвета выходят как в палитре. Пост-обработка (N8AO, MSAA в своём буфере) стоила 13 мс из 15 на кадр, сама сцена — 2. Её убрали, когда автор попросил ускорить игру.
- **Контактные тени.** Мягкий тёмный ореол у основания каждой постройки и ленты нарисован в текстуре земли (`Ground.tsx`, `CONTACT` в `balance.ts`). Он перерисовывается вместе с землёй, только когда что-то построили или убрали.
- **Тени солнца.** Карта 3072 на всю карту (`SHADOW`). Солнце слева сзади (`LIGHT.sunFrom`), тени ложатся вправо вниз, как в Tower Factory, около 0,4 клетки на клетку высоты (автор). Плоское — ложе лент, плитка — тени не отбрасывает, только принимает.
  Все числа — `CONTACT`, `SHADOW`, `LIGHT` в `balance.ts`. Обводки нет: автор её убрал.
- **Подсветка** (`Hover.tsx`). То, что под рукой (постройка, портал, овца), обводится тёплой светлой линией по силуэту. Проход рисуется, только пока что-то подсвечено. Это пакет `@kit/outline` из Cubocalypse (без скиннинга толпы): в буфер id попадает только этот объект, все его части с одним id, так что линия идёт по внешнему краю. `views` (`pick.ts`) хранит объекты сцены по клетке постройки и id овцы. Овцу под курсором находит луч по её модели (`pickAt`): сначала дешёвые сферы, потом точная модель только у тех, через чьи сферы прошёл луч; берётся ближняя к камере. Раньше брали овцу у точки на земле под курсором, а она лежит за спиной овцы, поэтому выделялась задняя. Это же работает для клика и перетаскивания, а под неподвижным курсором пересчитывается каждый кадр.
- **FPS.** Готовая панель `Stats` из drei (stats.js) внизу слева; клик переключает FPS, мс и память.
- **Камера.** Наклон 36°, узкий объектив (fov 20) издалека, как на образцах-диорамах: видна высота машин, а высокие предметы не заваливаются к краям экрана. Камера поворачивается вокруг точки взгляда (`cam.yaw`: Option- или правая кнопка с протяжкой, Q/E, два пальца вбок), наклон постоянный. WASD двигают камеру относительно взгляда.
- **Цена кадра.** Мелким деталям меньше граней: шарик меньше 0,05 клетки — 6 сегментов, скруглённый брусок тоньше 0,15 клетки — 1 сегмент скругления, крупнее — 2. Модели индексированы (`model` в `kit.ts`). Пачки instanced-мешей каждый кадр отправляют в видеокарту только занятую часть (`upload` в `instancing.ts`). Мерить — `__game.bench()`: целый кадр с ожиданием видеокарты.
- **Много одинаковых — один вызов.** Овцы (ноги, шуба, свалявшаяся шуба, репьи, стриженое тело, голова, хохолок; веки на время моргания; свой мягкий свет `sheepVmat`), корпуса и движущиеся части машин — instanced-меши, расставляемые за один проход кадра. Под `SHEEP.most` овец выделены меши; тень овцы отбрасывают три простых комка (`sheepShade*`); дальше `CAMERA.plainFlock` овцы упрощённые (`plain` в `models.ts`); овцы вне кадра не расставляются; позы считаются прямо в матрицы (`standAt`). HTML — только у овцы, которую сейчас стригут рукой (точки щелчков), и у знаков. Подсветка и выбор идут через невидимую копию модели в её позе.
- **Плотность пикселей сама подстраивается** под частоту кадров (`PerformanceMonitor` из drei): от 1 до плотности экрана, шагом 0,1.
- **Замер** (22.10.2026, окно 1024×768 при плотности 2, вся карта 112×112, `__game.bench`): 3000 овец — 2–4 мс за кадр без травы (вблизи и вся карта), с травой — 5 мс на обычном расстоянии и 8 мс на 85 клетках, где трава ещё рисуется. Показательная фабрика с 1100 овцами — 2–5 мс. `game/stress.ts` строит фабрику больше настоящей (`__game.stress(n)`, `stress.test.ts`: шаг меньше 1 мс).
- **Проверка.** Правила и чек-лист — [04-ART.md](04-ART.md). Кадры сверяет отдельный агент-критик: он сравнивает их с образцами и чек-листом.

### 4.3 HUD
React DOM поверх холста (`ui/Hud.tsx`, один файл стилей `styles.css`, БЭМ-классы). Данные HUD — простой снимок в `useHudStore`. Клики в HUD сразу действуют на мир (`actions/*`), следующее обновление показывает результат.

**Панели.** Слева сверху — монеты, счёт «острижено / цель» с полоской и следующий вид овец с числом стриженых до него; сверху — подсказка первых шагов и «убери не ту овцу» (`hintOf` в `GameLoop.tsx`); справа — скорость и меню; снизу — панель рецептов, снос и справочник. Карточка победы — «Играть дальше» или «Новая игра», с временем.

**Ножницы** (`ui/ShearCursor.tsx`). Пока рука над пушистой овцой (не на паузе, не несёт), за курсором идёт SVG ножниц, а сам курсор над холстом прячется (`body.is-shearing`). На клик лезвия смыкаются (`shear--snip`), под ними `HAND.shearClicks` точек по `SheepT.clicks`. Над неготовой овцой ножницы перечёркнуты (`shear--no`), щелчка нет. Рядом — её список: значок каждой нужды её вида (`NEED_ICON`: капля, гребень, пинцет), сделанное бледнее и с галочкой. Над стриженой — только значок портала у обычного курсора (`shear--shorn`). Читает мир каждый кадр сам, мимо `useHudStore`.
- **Значки** (`ui/Icon.tsx`). Постройки, виды овец, стриженая овца, портал, монета и ножницы — картинки `public/icons/<kind>.png`, отрисованные из их же моделей (`render/iconRender.ts`): тот же свет и полосы тона, что в поле, ортокамера спереди-справа-сверху по рамке модели, рисуется в 512 пикселей и ужимается до 160, под ней тёмная обводка. Список — `ui/iconKinds.ts`. Если модель изменилась, в дев-сборке надо выполнить `__game.icons()`: картинки перерисуются и сохранятся. Когда поле не запущено (скрытая вкладка), то же делает `(await import('/src/render/iconRender.ts')).renderIcons()`, а лист овец — `(await import('/src/render/sheepSheet.ts')).renderSheepSheet()`. Нарисованы остались только крестик сноса, замок и переключатель травы.

## 5. Бот баланса

`bot.ts`: `createBot(world).act(dt)` играет как игрок, одной рукой: каждый подход стоит `BOT.hand.act` секунд, между ними рука идёт `BOT.hand.speed` клеток в секунду. По порядку: снимает с ленты овцу, остановившую станцию или портал, и уносит в сторону; покупает рецепты простой линии — лента, Стрижка, морковка — как приходят монеты; строит линии от входов портала (`lines.ts`: морковка → лента → Стрижка → вход); в остальное время стрижёт рукой готовых овец у портала и носит их туда. Станций подготовки он пока не строит: когда прилетают грязные, его линии встают, а он только уносит неправильных.

`runBot(world, seconds)` играет без отрисовки и отдаёт, когда счёт дошёл до каждых 50 (`marks`: время, монеты, овцы на карте) и когда куплен каждый рецепт. `bot.test.ts` (`pnpm simulate`): за 15 минут больше 200 стрижек и рецепты в порядке лента, Стрижка, морковка; сейчас — 302 стрижки, 906 монет, 1602 овцы на карте.

## 6. Дев-инструменты

`window.__game` есть только в дев-сборке:

| Что | Что делает |
|---|---|
| `world`, `res(T)`, `traits` | доступ к живому миру |
| `coins(n)` | добавить монет |
| `shot(name)` | сохранить кадр 3D в полном разрешении в `docs/concept/shots/<name>.png` (без HUD) |
| `look(x, z, dist, yaw)` | поставить камеру над точкой поля, повернуть на `yaw` градусов |
| `info()` | частота кадров и время кадра на процессоре |
| `icons()` | перерисовать значки из моделей в `public/icons` |
| `sheep()` | нарисовать все виды овец на одном листе `docs/concept/shots/sheep-sheet.png` (`render/sheepSheet.ts`) |
| `stress(sheep)` | построить огромную рабочую фабрику для замеров (`game/stress.ts`) |
| `bench(n)` | сколько мс стоит целый кадр (симуляция, виды, тени, отрисовка) с ожиданием видеокарты |
| `r3f()` | состояние R3F, например его покадровые подписчики — чтобы засечь каждый |
| `app.setState({ grass })` | переключатели без сохранения |
| `speed(n)` | скорость |
| `start()` | начать новую игру |
| `unlockAll()` | открыть все постройки |
| `recipe(t)` | купить рецепт, как игрок |
| `autoplay(on, speed)` | бот играет вживую |
| `simulate(seconds)` | бот играет без отрисовки, печатает, когда счёт дошёл до каждых 50 |
| `showcase(warmup)` | достроить в этом мире линию от каждого входа портала (`showcase.ts`) |
| `project(x, z)` | точка поля → экран, для сценарных кликов |

Адрес `?play` сразу открывает игру (только в дев-сборке).
