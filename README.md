# Все овечки должны быть пострижены

Милая 3D-игра про конвейеры с овцами для браузера (по-английски — All Sheep Must Be Shorn). Овцы прилетают на парашютах на большую карту, и их надо постричь всех. Статуи-морковки приманивают овец к лентам, станции готовят их — Мойка, Расчёска, Щипалка, — Стрижка стрижёт, и стриженые уходят в портал в центре карты, за монеты. Товаров нет: по лентам едут только овцы. Low-poly из примитивов, React Three Fiber, koota. Дизайн — [docs/01-GDD.md](docs/01-GDD.md); прежняя игра «Овечья фабрика» — в истории git.

Репозиторий — pnpm-воркспейс:

| Пакет | Что это |
|---|---|
| `packages/game` | Игра. `pnpm dev` → `http://localhost:5173` |
| `packages/input` | `@kit/input`: действия клавиатуры по кодам клавиш |

## Запуск

```bash
pnpm install
pnpm dev
```

Проверки: `pnpm typecheck`, `pnpm lint`, `pnpm test` (один прогон на весь воркспейс). Сборка: `pnpm build` → `packages/game/dist`, пути относительные.

## Управление

| Что | Как |
|---|---|
| Рука | 3 клика по готовой (белой) овце — стрижка; у неготовой ножницы перечёркнуты, рядом — что ей нужно; клик по постройке — её окно |
| Овца | перетащить мышью: на ленту, в станцию, стриженую — в портал; Esc — опустить |
| Постройки | сначала купить рецепт в справочнике; 1–9 и 0 или панель внизу; R — повернуть; ПКМ или Esc — снова рука |
| Справочник | B или книжка у панели; клик — строить, 1–0 над постройкой — в ячейку панели |
| Лента | клик у выхода машины, клик у цели; или протянуть мышью |
| Снос | X над постройкой или инструмент «снос» с протяжкой |
| Перенос | ПКМ по машине или кнопка в её меню; Esc — вернуть на место |
| Камера | протянуть пустую землю, WASD или стрелки, колесо — ближе и дальше |
| Поворот камеры | Q/E, протяжка с Option или правой кнопкой, два пальца вбок |
| Трава | кнопка внизу справа (по умолчанию выключена) |
| Пауза | пробел; скорость ×1, ×2, ×4 — справа сверху |

## Баланс и консоль

`pnpm simulate` прогоняет бота 15 минут игры без отрисовки и печатает, когда счёт дошёл до каждых 50 (время, монеты, овцы на карте) и когда он купил каждый рецепт.

В дев-сборке есть `window.__game`:
- `__game.autoplay(true, 4)` — бот играет вживую на ×4;
- `__game.simulate()` — та же таблица в браузере;
- `__game.start()` — новая игра (или адрес `?play`, сразу без меню);
- `__game.showcase()` — линия от каждого входа портала;
- `__game.coins(500)`, `__game.recipe('carrot')`, `__game.unlockAll()`;
- `__game.bench()` — сколько мс стоит кадр.

## Графика

Файлов моделей нет: всё собрано в коде (`render/models.ts`, `render/machineModels.ts`) в стиле образцов из `docs/concept/refs`. Кадр в полном разрешении: `__game.shot('имя')` → `docs/concept/shots/имя.png`. Переключатели без сохранения: `__game.app.setState({ grass: true })`. Подсветка под курсором — пакет `packages/outline` (из Cubocalypse), FPS — панель stats.js внизу слева.
