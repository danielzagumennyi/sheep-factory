# Овечья фабрика

Милая 3D-игра про конвейеры и автоматизацию с овцами для браузера. Одна длинная игра: овцы ездят по петле через салон — Расчёску, Завивку, Вязку, Баню и Покраску, — а Стрижка снимает с них то, что выросло: шерсть, нитки, пряжу, свитера, войлок, обычные и цветные. Всё везут на большой рынок в середине острова: его клиенты постоянно берут каждый свой товар и с каждым уровнем хотят больше. Low-poly из примитивов, React Three Fiber, koota.

Репозиторий — pnpm-воркспейс:

| Пакет | Что это |
|---|---|
| `packages/game` | Игра. `pnpm dev` → `http://localhost:5173` |
| `packages/input` | `@kit/input`: действия клавиатуры по кодам клавиш |

## Запуск

```bash
pnpm install
pnpm dev
```

Проверки: `pnpm typecheck`, `pnpm lint`, `pnpm test` (один прогон на весь воркспейс). Сборка: `pnpm build` → `packages/game/dist`, пути относительные.

## Управление

| Что | Как |
|---|---|
| Рука | клик по пушистой овце (3 раза — стрижка, шерсть падает рядом); клик по кучке или покосу и кусту своей земли — в руку (до 6), кучку можно и перетащить; с грузом клик кладёт его: на рынок — на склад рынка, на голодную овцу — сено, на ленту, в машину, на землю; ПКМ или Esc — груз на землю; без груза клик по машине — её окно, по рынку — клиенты и торговля |
| Постройки | 1–9 и 0 или панель внизу; R — повернуть; ПКМ или Esc — снова рука (сначала кладут груз из руки) |
| Посев | инструмент «посев»: клик по пустой своей клетке — семя из руки (сено или краска, выбор в подсказке) |
| Справочник | B или книжка у панели; клик — строить, 1–0 над постройкой — в ячейку панели |
| Лента | клик у выхода машины, клик у цели; или протянуть мышью |
| Снос | X над постройкой или инструмент «снос» с протяжкой |
| Перенос | ПКМ по машине или кнопка в её меню; Esc — вернуть на место |
| Овца | перетащить мышью |
| Камера | протянуть пустую землю, WASD или стрелки, колесо — ближе и дальше |
| Поворот камеры | Q/E, протяжка с Option или правой кнопкой, два пальца вбок |
| Трава | кнопка внизу справа (по умолчанию выключена) |
| Пауза | пробел; скорость ×1, ×2, ×4 — справа сверху |

## Баланс и консоль

`pnpm simulate` прогоняет бота по главе 1 без отрисовки и печатает по каждому уровню: когда он закрылся, сколько шёл, сколько было покупок, самую долгую паузу между ними, сколько бот копил и сколько ему нечего было купить, заработано и потрачено, монеты и овцы; в конце — сколько всего он стоял без дела.

В дев-сборке есть `window.__game`:
- `__game.autoplay(true, 4)` — бот играет вживую на ×4;
- `__game.simulate()` — та же таблица в браузере;
- `__game.start()` — новая игра (или адрес `?play`, сразу без меню; `?play&endless` — бесконечный режим);
- `__game.showcase()` — достроить готовую ферму главы;
- `__game.coins(500)`, `__game.unlockAll()`.

## Графика

Файлов моделей нет: всё собрано в коде (`render/models.ts`, `render/machineModels.ts`) в стиле образцов из `docs/concept/refs`. Кадр в полном разрешении: `__game.shot('имя')` → `docs/concept/shots/имя.png`. Переключатели без сохранения: `__game.app.setState({ grass: true })`. Подсветка под курсором — пакет `packages/outline` (из Cubocalypse), FPS — панель stats.js внизу слева.
